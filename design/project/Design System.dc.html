Design system

Family Tree — foundations and component library

Tokens, primitives and tree-specific components for a multi-tenant genealogy SaaS. Arabic (RTL) is the primary locale; every token, component and layout rule below is direction-agnostic by construction. Values map one-to-one to CSS custom properties and Tailwind theme keys.

Radius & elevation

Radius
sm · 4
md · 8
lg · 12
xl · 16
pill
Controls (buttons, inputs, chips) use sm–md. Cards, panels and modals use lg. Tree nodes use md so they stay crisp when scaled down. Pill is reserved for badges and status dots.
Elevation
none — cards
low — nodes
med — popovers
high — modals
Shadows carry elevation only, never decoration. On the tree canvas only the selected node and hovered node raise; a canvas of 500 shadowed cards is visual noise and a paint cost.

ابحث في أفراد العائلة…
Mirrors
Layout axis · sidebar side · table column order · drawer edge · chevrons and arrows · progress and breadcrumb direction · tree growth direction · toolbar inset.
Does not mirror
Search glass · clock · trash · media controls · logos · phone numbers and email addresses · code and URLs (always LTR-isolated with bdi).
Every label is a translation key; no layout depends on a string's length. Buttons size to content with a min-width, tables use fractional columns, and numerals follow locale (Arabic-Indic in Arabic UI, Latin in English) while IDs and timestamps stay Latin.
15

Accessibility

Tree as a real widget
The canvas is a role="tree" with treeitem nodes carrying aria-expanded, aria-level and aria-setsize. Arrow keys walk siblings and generations, Enter opens the member panel, Space toggles a branch, and a live region announces “محمود, generation 4, 7 children, collapsed”.
Rules that hold everywhere
Focus is always visible at 2px with a 3:1 contrast against both surface and background. Dialogs trap focus and return it on close. Status is never color-only — it always pairs with a glyph or word. Errors are tied to inputs with aria-describedby. Every icon-only control has an accessible name in the active locale.
